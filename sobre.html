Sobre o Simulador de Eleições Brasileiro

Ferramenta interativa para simular cenários eleitorais brasileiros

Início Rápido

O Simulador de Eleições Brasileiro permite criar e visualizar diferentes cenários eleitorais de forma intuitiva e profissional.

  • 1
    Configure a Simulação

    Escolha entre 1º Turno ou 2º Turno e defina os candidatos com nome, partido, cor e foto.

  • 2
    Defina os Votos por Estado

    Clique em qualquer estado do mapa para abrir o modal e ajustar os percentuais de votos usando os sliders.

  • 3
    Visualize os Resultados

    Os resultados são atualizados em tempo real: totais nacionais, por região, gráficos e análises estatísticas.

Como Usar o Mapa

Desktop: Passe o mouse sobre um estado para ver informações rápidas. Clique para editar os votos.

Mobile: Toque uma vez para ver informações. Toque novamente para editar os votos.

Use a barra de busca acima do mapa para encontrar rapidamente qualquer estado digitando seu nome ou sigla.

Funcionalidades Principais

Candidatos Pré-definidos

Use o menu "Candidato pré-definido" para preencher automaticamente informações de candidatos conhecidos, incluindo foto e cor de campanha.

Salvamento Automático

Todas as alterações são salvas automaticamente no navegador. Você pode continuar de onde parou a qualquer momento.

Modo Escuro

Use o botão de tema no header para alternar entre modo claro e escuro. Sua preferência é salva automaticamente.

Dicas de Uso

  • Total de Votos: Os números são baseados nos votos válidos de 2022, com variações de 5% para projeção de 2026.
  • Percentuais: Os sliders garantem que a soma não ultrapasse 100%. Ajuste livremente para criar diferentes cenários.
  • Resetar: Use o botão "Resetar" na configuração para limpar todos os dados e começar uma nova simulação.
  • Resultados Regionais: Veja os resultados agrupados por região (Norte, Nordeste, Centro-Oeste, Sudeste, Sul) para análises mais detalhadas.

Perguntas Frequentes

Os dados são reais?

Os totais de votos por estado são baseados em dados reais de 2022, mas os percentuais de cada candidato são definidos por você na simulação.

Posso adicionar mais candidatos?

Atualmente, o simulador suporta 2 candidatos principais no 2º turno ou 2 candidatos + "Outros" no 1º turno.
